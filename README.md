# The Pecking Order

A cosy 3D game about a city pigeon, in one HTML file (formerly Crumb City). Play it at https://some1randomtg.github.io/crumb-city/

Fly across seven cities and a little bit of the moon, make friends, run errands and find out who really runs the pigeons.

Works in any modern browser on a computer, tablet or phone. Browsers with WebGPU get the new renderer; others keep the classic look. Progress is saved in your browser.

Current version: v446 (odd birds: every bird that isn't a pigeon is its own kind now, from dumpling gulls and the Magpie Mob to Bangcluck's hens in eight breeds and Coco the cockatoo, each with its own call and a bill that moves when it talks; before that v444, impressionable: a painted graphic novel that starts in Orsay, six living Impressionist paintings, three choices and a painted museum ticket for Plume; before that v445.1, lily pads: the Om pond has its lily pads back).
