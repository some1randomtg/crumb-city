# The Pecking Order

A cosy 3D game about a city pigeon, in one HTML file (formerly Crumb City). Play it at https://some1randomtg.github.io/crumb-city/

Fly across seven cities and a little bit of the moon, make friends, run errands and find out who really runs the pigeons.

Works in any modern browser on a computer, tablet or phone. Browsers with WebGPU get the new renderer; others keep the classic look. Progress is saved in your browser.

Current version: v344.1 (laptops and desktops start on the new renderer again: a reload or a closed tab in the first half-minute of a start no longer sends the next one to the classic look; a tidy-up of the whole game since v344: a fifth smaller to download, smoother late in the game and in Paree, Paree and the moon load behind a card, the Feather Tree twinkles again, town events pause with the menu, and the Jukebox keeps its bonus track)
