# The Pecking Order

A cosy 3D game about a city pigeon, in one HTML file (formerly Crumb City). Play it at https://some1randomtg.github.io/crumb-city/

Fly across seven cities and a little bit of the moon, make friends, run errands and find out who really runs the pigeons.

Works in any modern browser on a computer, tablet or phone. Browsers with WebGPU get the new renderer; others keep the classic look. Progress is saved in your browser.

Current version: v340 (every city runs a lot faster on the new renderer, about a quarter more frames a second in New Yolk and over a third more in Paree and Bangcluck, same look; the Jukebox is a record player with all 51 tunes and B-sides since v339.1; the once-a-second stutter in the big cities is a third of what it was since v339; phones start on the lighter renderer since v337; the big cities run 15 to 30% faster since v336, same look; arriving in a city stutters far less since v333; plus the minigames of v326 to v332)
