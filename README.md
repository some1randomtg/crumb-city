# The Pecking Order

A cosy 3D game about a city pigeon, in one HTML file (formerly Crumb City). Play it at https://some1randomtg.github.io/crumb-city/

Fly across seven cities and a little bit of the moon, make friends, run errands and find out who really runs the pigeons.

Works in any modern browser on a computer, tablet or phone. Browsers with WebGPU get the new renderer; others keep the classic look. Progress is saved in your browser.

Current version: v376 with v375 (less litter: the game throws away about half as much memory each second, so the pauses to clear it up come less often and are shorter, and every city runs faster; light traffic: the streets do less work for what is far away; on top of v374's fewer hitches in busy streets, v373's clearer corners and ledges, v365's smoother frames and the movement releases before them, and everything since v344.1)
