# The Pecking Order

A cosy 3D game about a city pigeon, in one HTML file (formerly Crumb City). Play it at https://some1randomtg.github.io/crumb-city/

Fly across seven cities and a little bit of the moon, make friends, run errands and find out who really runs the pigeons.

Works in any modern browser on a computer, tablet or phone. Browsers with WebGPU get the new renderer; others keep the classic look. Progress is saved in your browser.

Current version: v425 (bundled up, v425: a little smoother, the most when flying over New Yolk and Paree, with nothing on screen changed; then spring clean, v424: smoother again, about 5-7% more frames a second in New Yolk, Paree, Bangcluck and St. Petersbird, people coming into view no longer show stale faces or shadows, and the game now runs on three.js 0.187, which makes arriving in a city smoother and lets the night bloom round windows and neon show)
