# The Pecking Order

A cosy 3D game about a city pigeon, in one HTML file (formerly Crumb City). Play it at https://some1randomtg.github.io/crumb-city/

Fly across seven cities and a little bit of the moon, make friends, run errands and find out who really runs the pigeons.

Works in any modern browser on a computer, tablet or phone. Browsers with WebGPU get the new renderer; others keep the classic look. Progress is saved in your browser.

Current version: v444 (impressionable: a painted graphic novel that starts in Orsay, six living Impressionist paintings, three choices and a painted museum ticket for Plume; before that v445.1, lily pads: the Om pond has its lily pads back; before that v445, swim harder: Dam and Pok act, the trawler reads in the storm, Flush Hour gets an overflow vault, a jade Om, a neon soi with The Coop, and a pedal-boat swan).
